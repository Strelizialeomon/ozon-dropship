# ADR-20261007-build-in-house：直接自研履约中台，不以现成 ERP 起步

- 状态：生效中
- 日期：2026-10-07
- 决策人：用户（owner）
- 适用范围：整个项目的建设方式
- 取代：无
- 被取代：无
- 决策来源：[Issue #1 第二轮评论「需求拍板」第 7 条](https://github.com/Strelizialeomon/ozon-dropship/issues/1)（owner 点选「直接自研全套」）

## 决定

直接自研整套履约中台（Ozon 多店 × 中国货源），不先用现成 ERP 起步验证。

## 依据

- 调研的四家 ERP（妙手 / 店小秘 / 芒果 / 通途）都支持 Ozon 拉单 + 1688 代发，但采购下单环节**全是半自动**，无一支持「10+ 店全平台全自动」。
- 需求范围是中台级：手动 / 自动双轨、退货、财务对账、采集刊登全选，10+ 店、日 200–1000 单。

## 否决了什么

- 先用妙手 / 店小秘 / 芒果 / 通途任一家起步，再决定是否自研（ERP 对照数据留在 Issue #1 作 Plan B）。

## 接受的代价

- 开发与维护成本全部自担；自研系统跑通前，没有现成系统可用。

## 允许重开的条件

- 出现经实测能做到「1688 自动下单 + 10+ 店 + 手动/自动双轨」、且总成本明显低于自研的现成方案；
- 或自研第一波（S1）长期跑不通，owner 判断需要回到 Plan B。
