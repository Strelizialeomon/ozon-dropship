## 1. 管什么 / 不管什么

| 管 | 不管 |
|---|---|
| `internal/alibaba`：买家自用版（通道一）S1 用到的调用 | 何时下单、下单防重流程、人工渠道（S1-D） |
| 签名、授权与 token 续期、错误归一、接限流器 | 跨境自用版、免密支付、消息推送、商品关注（S2） |

## 2. 地盘

- **独占**：`backend/internal/alibaba/**`。
- **不碰**：其余全部。
- **依赖方向**：只依赖 `internal/infra`，不 import 业务包。token 要存进 `credentials` 表：本包定义一个小的「token 存取」接口，方法签名与 S1-A `store` 包对外的凭据读写方法对齐（见 S1-A §3 第 5 条），装配层把 `store` 接进来——**不改 `store` 的代码**（[ADR-20261007-go-package-deps-v2](../decisions/2026-10-07-go-package-deps-v2.md)）。
- **共享件**：装配接线要动 `cmd/api` 一行——先在 S1 父 issue 声明（总纲 §12.3 共享件规则）。

## 3. 对外方法清单（S1-D 据此在使用方定义小接口）

| 方法 | 用途 |
|---|---|
| `PreviewOrder` | 下单预览（运费、能否下单） |
| `CreateOrder` | 用 `alibaba.trade.fastCreateOrder` 下单：收货地址 = 中转点，买家留言带 `posting_number` |
| `GetOrder` | 订单详情：状态、实付金额 |
| `ListBuyerOrders` | 按时间窗查买家订单（下单防重核对用） |
| `GetLogistics` | 买家视角物流信息：国内段单号与轨迹 |

具体接口名以「采购解决方案（买家自用版）」在 1688 开放平台列出的为准（总纲 §7.2）。

## 4. 要做的事

1. **签名**：HMAC-SHA1，规则照 1688 官方签名文档；自写，不用第三方 Go 库。
2. **授权与 token**：`access_token` 10 小时有效，到期前用 `refresh_token` 续；续失败返回可识别的错误，供到期告警用（总纲 §5.8）。
3. 实现上表 5 个方法，请求经 S1-A 的限流器（1688 侧按「应用 + 接口」企业级桶；限额官方未公开【未验】——实测超限错误形态与退避，结论贴 S1 父 issue）。
4. **测试**：签名用官方 Java SDK 对同一组参数生成参考值对照；各方法 httptest + 录制响应。
5. **冒烟**（人工执行，会花真钱）：对一个老商家下一单低价商品，人工在 1688 付款，再查订单和物流。

**外部前置**：1688「买家自用版」权限**申请中**——企业实名 + 买家等级 ≥ L2 为门槛（总纲 §12.1），下单类权限按月续订。没批也能按录制响应开发；冒烟等批下来再做。

## 7. 自定细节

- 方法命名如第 3 节表；token 存 `credentials` 表，`kind = alibaba_token`，经 S1-A 的保险箱加密；1688 token 属于企业账号、不属于某个店，`store_id` 为空 = 企业级凭据（总纲 §6 口径）。
- 冒烟会花真钱：对老商家下一单低价商品、人工在 1688 付款（总纲 §9·S1 联调用）。
- 录制响应放 `internal/alibaba/testdata/`；冒烟测试构建标签 `smoke`。
- token 缓存策略（实施期定，2026-10-07）：应用密钥内存缓存 10 分钟（轮换后最多 10 分钟生效，不用重启）；access_token 命中缓存直用，冷启动后首次调用必续期一次（库里存的是 refresh_token 到期时间，判断不了 access_token 状态——宁多续一次，不拿未知状态的 token 撞网关）；续期失败进 30 秒冷却窗口（窗口内并发调用直接拿到同一错误，不放大请求）；业务响应出现鉴权失败码（InvalidSession 等，清单【未验】）时清 token 缓存，下次调用自愈。
- 下单不做盲目重试（实施期定）：`fastCreateOrder` 只在确定被拒（限流/超限，没执行）时于客户端内重试；5xx / 超时 / 响应解不出来一律直接上抛——那可能是「订单已建、回包丢了」，交 S1-D 防重流程核对（先查买家订单再决定补记或重发）。
- 请求可选参数的默认：`flow` 空 = `general`；订单列表 `page` 空 = 1、`pageSize` 空 = 50、`isHis` 默认 false；`GetOrder` 固定带 `includeFields=NativeLogistics`。
- 续期成功后回写失败的兜底：新 token 留在内存继续用（只记警告），不把已换到手的 token 丢掉——响应若轮换了 refresh_token，丢弃新值等于把后续所有调用推向「需人工重新授权」。
