# 线路实测 —— 服务器选址（国内 / 香港 / 新加坡）

> 总纲 §13.2：服务器放哪由实测决定，不是拍脑袋。本脚本在各地机器上跑 24 小时，产出
> P50 / P95 延迟与失败率；汇总表即选址结论的依据。
> ⚠️ 租三地按量机要花钱——**跑前先确认预算**；跑完即释放。

## 怎么跑

在**每台**目标地区的机器上（国内 / 香港 / 新加坡各一台，按量买最便宜的即可）：

```bash
scp -r deploy/line-test/  root@<地区机器>:/root/line-test/
ssh root@<地区机器>
cd /root/line-test
nohup ./line_test.sh -d 24h -i 60 > run.log 2>&1 &
# 24 小时后（或想提前收）：
tail -n 3 run.log              # 看是不是还在跑
kill <脚本进程号>               # 停止用 TERM（kill 默认信号）：会收尾并写出 summary.md；
                               # 后台作业里 SIGINT 会被系统忽略，Ctrl-C 语义在这里没用
cat results-*/summary.md       # 这就是要贴的表
```

机器只要 curl + awk + sort（发行版自带）；不需要任何凭据。
想让 Ozon 那条顺手验「鉴权也通」：在目录里放 `auth.env`（chmod 600）写
`OZON_CLIENT_ID=...` 与 `OZON_API_KEY=...`，答 200 即通；不放就只看网络路径。

把三台的 `summary.md` 收回本地（`scp -r root@<机器>:/root/line-test/results-* .`），
按下面的模板拼报告。

## 报告模板

```markdown
## 线路实测报告（<起> ~ <止>）

| 地区 | 机器（云商 / 型号 / 出口 IP） | ozon 失败率 | ozon P50/P95 (ms) | 1688 失败率 | 1688 P50/P95 (ms) |
|---|---|---|---|---|---|
| 国内 | | | | | |
| 香港 | | | | | |
| 新加坡 | | | | | |

- 探测口径：24h × 每 60s；只调只读接口（Ozon /v1/roles、1688 currentTime）；
  失败 = 超时/连不上/TLS 错/HTTP ≥ 500；原始数据随附（附件或粘贴片段）。
- 结论建议：<我认为放 X 好，理由一句话> —— 最终由跑实测的人拍板。
```

## 判定与口径

- **失败** = curl 出错（超时 / 连不上 / TLS 错）或 HTTP ≥ 500。未鉴权的 401 / 400
  算「可达」——服务端答话了，就证明这条线路通。
- P50 / P95 = 最近秩（nearest-rank），只统计成功样本；数据单位秒，汇总时换算毫秒。
- 首字节（TTFB）与总时间都记：TTFB 看服务端响应速度，总时间含 TLS 握手，更能代表真实请求成本。
- `raw.csv` 逐条留档：时间戳、目标、状态码、DNS / TCP / TLS / TTFB / 总耗时，出争议时对得上。
